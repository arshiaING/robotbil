# Robotbil med Mecanum-hjul

Vi skal lage og programmere en robotbil.
Vi bruker Ada på Micro:bit V2.

## Målet med prosjektet

Bilen skal kunne kjøre fremover, bakover, sidelengs og rotere.
Den skal bruke sensorer til å oppdage hindringer og etter hvert
kunne unngå dem selv.

Vi skal også lære å kjøre flere oppgaver samtidig og ta hensyn
til tidskrav og sikkerhet.
